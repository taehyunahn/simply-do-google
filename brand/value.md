## 왜 심플리Do인가?

### 핵심 차별점: 통역할 수 있는 개발자

일반 개발자는 기술을 잘 안다. 하지만 사장님의 모호한 요구사항을 알아듣고, 그걸 기술로 옮기고, 다시 사장님의 언어로 설명하는 건 다른 능력이다.

경영학을 전공하고, 실무 현장에서 직접 일하다가, 개발을 배운 사람이기 때문에 이 통역이 가능하다.

### vs. 일반 개발 외주

| | 일반 외주 | 심플리Do |
|---|---------|---------|
| 소통 | 기술 용어 위주, 사장님이 맞춰야 함 | 사장님의 언어로 대화 |
| 제안 | 최신·고급 기술 중심 | 상황에 맞는 적정기술 |
| 결과물 | 화려하지만 관리가 어려움 | 직접 관리할 수 있는 수준 |
| 비용 | 수백만 원~ | 25만 원~ |

### vs. SaaS / ERP

| | SaaS / ERP | 심플리Do |
|---|-----------|---------|
| 학습 비용 | 새 프로그램 학습 필요 | 이미 쓰는 구글 시트 그대로 |
| 월 비용 | 월 구독료 지속 발생 | 일회성 구축비 |
| 맞춤화 | 정해진 틀 안에서만 가능 | 업무에 맞게 100% 맞춤 |
| 데이터 | 플랫폼에 종속 | 내 구글 드라이브에 보관 |
