# 서비스 라인업

## 서비스 구조

심플리Do의 서비스는 **"만들어 드림"**과 **"알려 드림"** 두 축으로 나뉜다.

---

## 만들어 드림 (제작 서비스)

### 1. 랜딩페이지 제작 (포트폴리오 구축 단계)

- **URL**: simplydo.kr/landing
- **현재 가격**: 치킨값 22,000원 (포트폴리오 구축을 위해 선착순 10명 한정)
- **수정 비용**: 이미지·문구 등 간단한 변경(1시간 내외) — 커피 한잔 4,500원
- **정상 가격**: 추후 포트폴리오 확보 후 책정 예정
- **설명**: 전환율 높은 이벤트·프로모션 랜딩페이지를 빠르게 제작
- **타겟**: 프로모션/이벤트를 앞둔 사업자
- **특징**: 모바일 최적화, 빠른 납기, 수정 용이
- **호스팅**: Cloudflare Pages / Vercel / Netlify 등 무료 클라우드 호스팅으로 배포 → 월 유지비 0원
- **도메인**: 고객이 직접 구매 (연 1~2만 원 수준) → 소유권도 고객 본인에게
- **핵심 셀링포인트**: 제작비 치킨값 + 유지비 0원. "만들고 나서도 돈 안 드는 랜딩페이지."
- **현재 전략**: 거의 무료 수준으로 실제 고객 작업을 쌓아 포트폴리오와 후기를 확보하는 단계. 가격이 아닌 결과물로 신뢰를 만든다.

### 2. 구글시트 기반 업무 자동화

- **URL**: simplydo.kr/crm
- **단가**: 별도 협의 (규모에 따라 상이)
- **설명**: 예약·고객·매출·알림을 구글 시트 위에서 자동 관리
- **타겟**: 반복 업무에 시간을 뺏기는 소상공인
- **특징**: 기존 구글 워크스페이스 활용, 카카오 알림 연동

### 3. 맞춤형 업무 프로그램 개발

- **단가**: 별도 협의
- **설명**: 웹 포털, 관리 시스템 등 규모가 큰 맞춤 개발
- **구축 사례**:
  - 파트너 계약·커미션 관리 웹 포털
  - 해외 지사 통합 입학 신청·서류 관리 포털
  - 직원 연차·휴가 관리 자동화 시스템

## 알려 드림 (교육 서비스)

### 4. 스프레드시트 / 엑셀 활용 교육

- **상태**: 유튜브 무료 콘텐츠 운영 중
- **설명**: 구글 시트·엑셀 실무 활용법
- **채널**: YouTube @심플리Do

### 5. 바이브코딩 교육

- **상태**: 준비 중
- **설명**: 구글 워크스페이스 + AI를 활용한 업무 자동화, 직접 배워서 하기
- **형태**: 전자책 + 1:1 코칭 (예정)

---

## 서비스 퍼널

```
유튜브 무료 콘텐츠 (인지)
    ↓
무료 템플릿 / 전자책 (리드 수집)
    ↓
교육 / 코칭 (저가 전환)
    ↓
랜딩페이지 제작 — 치킨값으로 진입 장벽 낮춤 (포트폴리오 확보)
    ↓
자동화 / 맞춤 개발 (고가 전환)
```
